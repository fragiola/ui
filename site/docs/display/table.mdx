The grid is `border-palette-line`. The header is `bg-palette-soft`. A selected row (`data-state="selected"`) is `soft` too, and a hover is half of it, so a hover never reads as selected: the same treatment as a tree row or a data-grid row. Header text is `text-palette-contrast`, and body text is `text-palette-accent/85`.
