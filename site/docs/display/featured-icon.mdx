A featured icon draws the eye to what a block is about: it leads an [Empty](/docs/display/empty)
state, a confirmation, a row of features. Pass the icon as its child. It is decorative by
default (`aria-hidden`), because the text beside it says what it means; when it stands alone,
give it `role="img"` and an `aria-label`, and it is no longer hidden.

## The look

It adds no family. A circle filled with the palette's `soft` tint, with the icon in its `accent`:
the soft [Badge](/docs/display/badge)'s pair of roles. On the floor it is a neutral grey; under a
chromatic palette, that palette's tint. The size is a class (`size-10` by default, `size-12` in
Empty, `size-14` above), and the icon is the standalone illustration size (`size-icon-lg`, which
follows the typography axis) unless it sets its own. There is no size or colour variant.

## Bases

**Markup only.** The featured icon imports no primitive, so it is one shared file
(`ui/featured-icon.tsx`), the same on both bases.
