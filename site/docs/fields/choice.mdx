## Style family

The `choice` family has five members — `root`, `control`, `indicator`, `label`, `description` — and zero variants. Checkbox and Radio use `root` + `indicator`; Switch uses `root` (the track) + `control` (the thumb). Each component overrides only what differs: Radio adds `rounded-full`, Switch adds `w-9 h-5 rounded-full` and a translate on the thumb.

## Field.ChoiceRoot

Checkable controls use `Field.ChoiceRoot` instead of `Field.Root` — a horizontal row (control on the left, label on the right) instead of a vertical column. The same Label, Description and Error members are reused.

## State normalization

Both bases emit `data-checked` and `data-unchecked` (not `data-state=checked`). Unchecked, a checkbox or a radio is a control box, the same `line` stroke as a field. Checked, it takes the foundation's `checked` member: the box fills with `ring`, the colour of every "on" state (a switch, a slider, a progress bar), and the check or dot inherits the box's text colour, `base`. A switch is the choice family's `track` and `thumb`: the track is `line` when off and `ring` when on, the same two colours as a slider. See [the visual language](/docs/architecture/style-families).
